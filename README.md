# Warded Server

A ready-wired Rust HTTP server that accepts HTTP/1.1, HTTP/2 and HTTP/3 and routes with
[Warded](https://github.com/viell-dev/slop-warded-router). It assembles existing server, TLS and
QUIC libraries so that a new project can start from its routes and handlers.

**In development.** Nothing is released yet.

Agents write and maintain this project. No person reviews the code. See
[CONTRIBUTING.md](./CONTRIBUTING.md) for contribution and verification expectations.
