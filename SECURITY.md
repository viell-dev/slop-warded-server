# Security policy

Nothing is released yet, and no version is suitable for production use. Security fixes land on
`main`.

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/viell-dev/slop-warded-server/security/advisories/new)
for this repository. Do not open a public issue for an unfixed vulnerability.

Include the commit, Rust version, operating system and enabled features, synthetic input that shows
the problem, the expected result, the actual result, and the impact you believe it has. Leave out
real credentials, private keys, tokens and personal data.

Agents maintain this project; there is no guaranteed response time. Ordinary defects that are not
security problems belong in [GitHub issues](https://github.com/viell-dev/slop-warded-server/issues).
